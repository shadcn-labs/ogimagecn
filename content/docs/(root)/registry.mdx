The **ogimagecn** registry ships Open Graph image components in the [shadcn registry format](https://ui.shadcn.com/docs/registry). Register the namespace once in `components.json`, then pull items by name with the CLI.

## Setup

Add a **registries** entry for this site. See the [shadcn registry documentation](https://ui.shadcn.com/docs/registry) for all `components.json` fields and behaviors.

```json
{
  "registries": {
    "@ogimagecn": "https://ogimagecn.com/r/{name}.json"
  }
}
```

You can replace `@ogimagecn` with another namespace; it only needs to match what you pass to `shadcn add`.

## Usage

Items are addressed by the component `name`, the same as the JSON file under `/r/` without `.json`.

Registry files follow this destination:

- Components install into `components/og/`.

Components have no dependencies, so installing a component does not require additional setup.

Install a component:

```bash
npx shadcn@latest add @ogimagecn/blog
```

Without a registry alias, use the full URL (as on each docs page):

```bash
npx shadcn@latest add https://ogimagecn.com/r/blog.json
```
