[MCP](https://modelcontextprotocol.io/) is an open protocol that standardizes how applications provide context to LLMs. The shadcn CLI can register an MCP server so your editor can discover registry components—including items you install from **ogimagecn** via the same CLI.

## Configure MCP

Run:

```bash
npx shadcn@latest mcp init
```

Choose your MCP client when prompted, then enable the MCP server in that client to finish setup.

## Usage

With MCP enabled, you can ask your IDE to work with **Satori** patterns and ogimagecn registry components. Example prompts:

- Generate a **Blog** OG image with category, author, and excerpt for every post.
- Create a **Changelog** card listing the highlights of a release.
- Build a **Product** OG image with a product shot and price.
- Turn a testimonial into a **Quote** card with the author row.
- Make a **Stat** card with a large number, trend pill, and caption.

Install components from this registry with `npx shadcn@latest add` and the JSON URL from each docs page. Components work with sensible defaults.
