## Usage

```tsx
import { StarRating } from "@/components/og/star-rating";
```

```tsx
<StarRating score="4.5" size={64} value={4.5} />
```

Fractional values fill part of a star, so `4.5` draws four full stars and a half. The value is clamped between 0 and `max`. Pass `score` to show a pill with that text beside the stars.

## API Reference

| Prop         | Type               | Default                    |
| ------------ | ------------------ | -------------------------- |
| `value`      | `number`           | required                   |
| `max`        | `number`           | `5`                        |
| `size`       | `number`           | `48`                       |
| `color`      | `string`           | `"#facc15"`                |
| `emptyColor` | `string`           | `"rgba(250,250,250,0.18)"` |
| `score`      | `number \| string` | none                       |
