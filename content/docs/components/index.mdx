---
title: Components
description: Satori-safe primitives that the ogimagecn blocks are built from.
---

Components are the small pieces every [block](/docs/blocks) is made of. They
already follow Satori's rules — explicit `display: "flex"`, units on every
length, no `alt` text on images — so you can compose your own Open Graph images
without tripping over them.

Blocks install the components they use automatically. Install a component on its
own when you are building a custom image.
