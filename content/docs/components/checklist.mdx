## Usage

```tsx
import { Checklist } from "@/components/og/checklist";
```

```tsx
<Checklist
  color="#34d399"
  gap={24}
  items={["Unlimited projects", "Custom domains", "Priority support"]}
  size={40}
/>
```

Items render in the order given, each with its own checkmark. `color` only tints the checkmarks; the text inherits its color from the parent. `size` sets both the checkmark and the font size, and long items wrap with the checkmark aligned to the first line. An empty array renders an empty list.

## API Reference

| Prop    | Type       | Default     |
| ------- | ---------- | ----------- |
| `items` | `string[]` | —           |
| `color` | `string`   | `"#34d399"` |
| `gap`   | `number`   | `20`        |
| `size`  | `number`   | `34`        |
