## Usage

```tsx
import { GridLines } from "@/components/og/ui/grid-lines";

<div
  style={{
    display: "flex",
    height: "100%",
    position: "relative",
    width: "100%",
  }}
>
  <GridLines inset={64} color="#44403c" variant="dashed" />
  {/* content */}
</div>;
```

Satori has no `z-index`: place `GridLines` first inside a `position: "relative"` parent so later siblings paint above it.

## API Reference

| Prop      | Type                  | Default     |
| --------- | --------------------- | ----------- |
| `inset`   | `number`              | `64`        |
| `color`   | `string`              | `"#44403c"` |
| `variant` | `"solid" \| "dashed"` | `"dashed"`  |
