## Usage

```tsx
import { ImageResponse } from "next/og";

import { DitherRegistry } from "@/components/og/dither-registry";

export function GET() {
  return new ImageResponse(
    <DitherRegistry
      registry="@acme/ui"
      title="Ship your design system as code."
      description="Composable components your team and coding agents can install in one command."
      command="npx shadcn@latest add @acme/button"
      accent="#28d26e"
    />,
    { width: 1200, height: 630 }
  );
}
```

## How the bitmap works

The component paints a premultiplied RGBA buffer using an ordered 4×4 Bayer
matrix. The shared helper unpremultiplies and encodes that buffer once as PNG,
then Satori reuses the encoded image for the crisp and blurred layers. No SVG
node is created for each dither cell.
