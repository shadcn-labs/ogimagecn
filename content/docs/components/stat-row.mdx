## Usage

```tsx
import { StatRow } from "@/components/og/stat-row";
```

```tsx
<StatRow
  columns={3}
  divider
  stats={[
    { label: "Stars", value: "12.4k" },
    { label: "Forks", value: "1.8k" },
    { label: "Contributors", value: "96" },
  ]}
/>
```

Omit `columns` to keep every stat in one row, or drop `divider` for plain spacing between columns.

## API Reference

| Prop      | Type                                 | Default |
| --------- | ------------------------------------ | ------- |
| `stats`   | `{ label: string; value: string }[]` | —       |
| `divider` | `boolean`                            | `false` |
| `columns` | `number`                             | —       |
