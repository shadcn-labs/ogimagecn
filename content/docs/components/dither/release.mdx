## Usage

```tsx
import { ImageResponse } from "next/og";

import { DitherRelease } from "@/components/og/dither-release";

const geistPixel = fetch(
  "https://raw.githubusercontent.com/vercel/geist-font/main/fonts/GeistPixel/ttf/GeistPixel-Square.ttf"
).then((response) => response.arrayBuffer());

export async function GET() {
  return new ImageResponse(
    <DitherRelease
      brand="Acme"
      eyebrow="Product update"
      title="A faster way to ship."
      description="Faster workflows, clearer feedback, and a calmer path from idea to production."
      buttonLabel="Read the changelog →"
      variant="gradient"
      accent="#9f7aea"
      accentTo="#ec8fbd"
    />,
    {
      width: 1200,
      height: 630,
      fonts: [
        {
          name: "Geist Pixel",
          data: await geistPixel,
          style: "normal",
          weight: 400,
        },
      ],
    }
  );
}
```

## How the bitmap works

The shared bitmap helper paints the supporting gradient and CTA texture. The
button can use the gradient, dotted, hatched, or solid variant without turning
the rest of the product-release OG into a component showcase.
