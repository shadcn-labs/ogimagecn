## Usage

```tsx
import { ImageResponse } from "next/og";

import { DitherProfile } from "@/components/og/dither-profile";

const geistPixel = fetch(
  "https://raw.githubusercontent.com/vercel/geist-font/main/fonts/GeistPixel/ttf/GeistPixel-Square.ttf"
).then((response) => response.arrayBuffer());

export async function GET() {
  return new ImageResponse(
    <DitherProfile
      name="Ada Lovelace"
      handle="@ada"
      website="ada.dev"
      eyebrow="Author profile"
      title="Designing systems that feel human."
      description="Notes on software, systems, and the people who make them."
      accent="#a885f3"
    />,
    {
      width: 1200,
      height: 630,
      fonts: [
        {
          name: "Geist Pixel",
          data: await geistPixel,
          style: "normal",
          weight: 400,
        },
      ],
    }
  );
}
```

## How the bitmap works

The shared bitmap helper contains every Dither primitive. For this profile OG,
the name seeds 32 bits across half of an 8×8 grid and mirrors them into a
deterministic avatar. A cached gradient bitmap provides the supporting accent.
