## Usage

```tsx
import { TerminalFrame } from "@/components/og/terminal-frame";
```

```tsx
<TerminalFrame title="~/my-app">
  <div style={{ display: "flex" }}>$ npx shadcn@latest add @ogimagecn/blog</div>
  <div style={{ display: "flex" }}>Created components/og/blog.tsx</div>
</TerminalFrame>
```

Each child is one row. The last row shows `prompt` followed by a cursor. Pass `prompt=""` to hide it.

Satori only draws fonts you pass to it. To get monospace rows, load a monospace font and set `fontFamily` to its name.

## API Reference

| Prop         | Type            | Default       |
| ------------ | --------------- | ------------- |
| `children`   | `ReactNode`     | none          |
| `title`      | `string`        | none          |
| `prompt`     | `string`        | `"$"`         |
| `fontFamily` | `string`        | `"monospace"` |
| `fontSize`   | `number`        | `28`          |
| `style`      | `CSSProperties` | none          |
