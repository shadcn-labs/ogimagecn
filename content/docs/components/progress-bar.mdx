## Usage

```tsx
import { ProgressBar } from "@/components/og/progress-bar";
```

```tsx
<ProgressBar color="#a78bfa" label="Funding goal" showPercent value={72} />
```

The fill is `value / max`, clamped between 0 and 100%. The label row only renders when `label` or `showPercent` is set.

## API Reference

| Prop          | Type      | Default                    |
| ------------- | --------- | -------------------------- |
| `value`       | `number`  | required                   |
| `max`         | `number`  | `100`                      |
| `label`       | `string`  | none                       |
| `showPercent` | `boolean` | `false`                    |
| `color`       | `string`  | `"#a78bfa"`                |
| `trackColor`  | `string`  | `"rgba(250,250,250,0.12)"` |
| `height`      | `number`  | `16`                       |
| `gap`         | `number`  | `14`                       |
