## Usage

```tsx
import { ImageResponse } from "next/og";

import { ComingSoon } from "@/components/og/coming-soon";
```

```tsx
export function GET() {
  return new ImageResponse(
    <ComingSoon
      brand="ogimagecn"
      date="Launching October 20, 2026"
      title="Something new is coming."
    />,
    { width: 1200, height: 630 }
  );
}
```

## API Reference

### ComingSoon

| Prop    | Type     | Description                                                        |
| ------- | -------- | ------------------------------------------------------------------ |
| `brand` | `string` | Brand name. Its first letter is used when no logo is provided.     |
| `title` | `string` | Teaser headline.                                                   |
| `date`  | `string` | Launch date chip text, displayed as provided.                      |
| `logo`  | `string` | Optional logo URL or data URI. Supports PNG, JPEG, and GIF images. |
