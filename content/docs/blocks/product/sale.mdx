## Usage

```tsx
import { ImageResponse } from "next/og";

import { Sale } from "@/components/og/sale";
```

```tsx
export function GET() {
  return new ImageResponse(
    <Sale
      brand="ogimagecn"
      title="The OG image toolkit"
      discount="-40%"
      event="Black Friday sale. Four days only."
      dates="Nov 27–30, 2026"
      coupon="SAVE40"
    />,
    { width: 1200, height: 630 }
  );
}
```

## API Reference

### Sale

All props are required except `logo`, which displays a blank indigo tile when omitted.

| Prop       | Type     |
| ---------- | -------- |
| `brand`    | `string` |
| `title`    | `string` |
| `discount` | `string` |
| `event`    | `string` |
| `dates`    | `string` |
| `coupon`   | `string` |
| `logo`     | `string` |
