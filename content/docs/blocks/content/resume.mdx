## Usage

```tsx
import { ImageResponse } from "next/og";

import { Resume } from "@/components/og/resume";
```

```tsx
export function GET() {
  return new ImageResponse(
    <Resume
      name="Ada Rivera"
      role="Senior Frontend Engineer"
      skills={["React", "TypeScript", "Next.js", "Design systems", "Satori"]}
      url="adarivera.dev"
    />,
    { width: 1200, height: 630 }
  );
}
```

The name and role stay on one line each and end with an ellipsis when they are too long. Skills wrap to at most two rows. Chips past the second row are hidden.
